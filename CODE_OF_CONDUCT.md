# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Reporting

Report unacceptable behavior privately through
[GitHub Security Advisories](https://github.com/murasame29/workload-knocker/security/advisories/new)
or by contacting the maintainer, [@murasame29](https://github.com/murasame29), via the
contact details on the GitHub profile.
